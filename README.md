# What's New These Days

Threat intelligence briefs built from open sources, published at
https://searchinginthedark.github.io/whats-new-these-days/

Each brief lives in `briefs/<case>/index.html`; `briefs/manifest.json` lists them.

- Indicators of compromise are defanged (`198.51.100[.]1`). Re-fang deliberately.
- Briefs reflect public reporting at the time of writing. They are not advice and
  are not updated after publication unless the page says so.
- Some analytic sections are withheld from the public edition.

This repository is generated. Pages are added by a publishing tool, not edited by hand.
